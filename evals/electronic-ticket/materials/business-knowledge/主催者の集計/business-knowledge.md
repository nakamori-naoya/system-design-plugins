# 主催者の集計の業務知識

主催者と作り手が、一つの公演で何枚が売れ、何枚が分配され、何枚がリセールで移り、何人が入場したかを、同じ数え方で判断するための業務知識である。この業務は、主催者が自分の公演の集計を見ようとしたときに始まり、四つの数を見たところで終わる。数の根拠になる事実は販売、チケット、リセール、入場の業務が成立させ、この業務はそれを数えるだけで、何も変えない。

# 概要

主催者の集計は、主催者が自分の公演でチケットがどう売れ、どう人の手を渡り、どれだけの人が来たかを知るために、ほかの業務が成立させた事実を公演ごとに数える業務である。紙のチケットの時代、主催者は誰が今の持ち主かを知らなかった（業務要件「なぜ作るのか」）。ステージパスでは購入、分配、リセール、入場がすべて記録されるので、主催者は「売れた枚数」「分配された枚数」「リセールで移った枚数」「入場した人数」を一つの答えとして受け取れる（業務要件「後から説明できること」）。数え方がそろっていないと、同じ公演を見た主催者と運営スタッフが違う数を口にし、主催者は次の公演の席の数やリセールを許すかを誤った数で決めることになる。

この業務は、チケットを売らず、分けず、移さず、入場させない。購入の成立は販売の業務が、分配はチケットの業務が、出品とリセールの購入はリセールの業務が、入場は入場の業務が、払い戻しは払い戻しの業務が担う。公演と主催者は主催者の管理機能が持ち、この業務は所与として扱う。主催者向けの売上の精算は初期リリースの対象外なので（業務要件「対象外」）、金額は数えない。通信断の間に起きた入場の食い違いを係員と主催者へ知らせるのも入場の業務である。

## 業務用語

### 公演の集計

一つの公演について、見た時点までにほかの業務が成立させた事実から数えた、売れた枚数、分配された枚数、リセールで移った枚数、入場した人数の四つの数である。一回に見るのは一公演の集計で、公演をまたいで足し合わせた数ではない（仮説。「まだ決まっていないこと」参照）。

### 売れた枚数

その公演で、販売の業務で購入が成立したチケットの枚数である。リセールの購入は、同じチケットの持ち主が変わるだけなので数えない。数えないと一つの席が二枚売れたことになるからである。当選しただけで代金を払っていない来場者の分、先着で席を確保しただけの分、席が無く購入を成立させずに代金を返した分は、購入が成立していないので数えない。

### 分配された枚数

その公演で、同行者が分配を承諾し、保有者が同行者に変わったチケットの枚数である。承諾されるまで保有者は購入者のままなので（業務要件「同行者への分配」）、承諾を待っている分配と、承諾の前に取り消された分配は数えない。同じチケットは一枚として数える（仮説）。

### リセールで移った枚数

その公演で、リセールの購入が成立し、保有者が買い手に変わったチケットの枚数である。買い手が代金を払うまで権利は出品者にあるので（業務要件「買う」）、出品中の出品、取り下げた出品、締切で取り下げられた出品は数えない。同じチケットがリセールで二度移っても一枚と数える（仮説）。

### 入場した人数

その公演で、一度でも入場したチケットの枚数である。一枚のチケットで同時に入場できるのは一人だけなので、チケットの枚数を人数とする。再入場は同じ人の二度目の入場なので重ねて数えない（仮説）。確認窓口で係員が認めた入場は入場なので数え、止められたチケットは数えない。

## 業務イベント

この資料が持ち主の業務イベントは無い。この業務は事実を成立させず、ほかの業務の事実を数えるだけだからである。

# 概念

## 公演の集計は、持ち主の業務の事実から数えるもので、この業務の中に事実を持たない

公演の集計は、購入、分配、リセールの購入、入場という持ち主の違う四つの事実を、一つの公演について同じ時点で数えた答えである。この業務は数を覚えておく必要がない。事実が増えれば数も増え、事実を見れば数を誰でも数え直せるからである。数が主催者の見たものと合わないとき、根拠をたどる先は持ち主の業務の事実である。

四つの数は互いに独立に数える。分配されたチケットがその後リセールで移れば、分配された枚数とリセールで移った枚数の両方に一枚ずつ入る。払い戻しになったチケットも、それまでに成立した購入、分配、リセールの購入は起きた事実なので、それぞれの数から減らさない（仮説）。

見た時点までに持ち主の業務が記録していない事実は、まだ数に入らない。通信が切れていた入口で起きた入場は、端末が通信の戻った後にまとめて送り、入場の業務が受け取った時点で入場した人数に入る（業務要件「通信が切れているとき」）。

# 常に守られること

### 一枚のチケットは、四つの数のそれぞれに多くとも一枚として入る

同じチケットを二度数えると、主催者は席の数より多い入場やリセールを見て、実際の売れ行きと来場を取り違える。再入場や二度のリセールや、通信断の間に同じチケットが二つの入口で使われたときも、数は一枚である。

### 公演の集計は、その公演のチケットの事実だけから数える

別の公演のチケットが混ざると、同じツアーの別の日を別の公演として扱う決まり（業務要件「初期リリースで扱う公演」）が集計で崩れ、主催者は日ごとの来場を比べられなくなる。

### 公演の集計を見ても、どの業務の事実も変わらない

集計を見ることがチケットの保有者や入場の可否を変えれば、来場者と係員が見る答えと主催者が見る答えがずれる。この業務はコマンドを持たない。

### 公演の集計の数は、持ち主の業務の事実から誰でも数え直せる

主催者が「売れた枚数が合わない」と問い合わせたとき、運営スタッフは持ち主の業務の事実を公演ごとに数え直して答える（仮説。この業務が独自に説明のための記録を残さないことは「まだ決まっていないこと」参照）。一枚ごとの購入、分配、リセール、入場の順序を説明するのは、それぞれの持ち主の業務の決まりである。

# 状態と、その移り変わり

状態を持たない。公演の集計は見た時点の数で、始まりも終わりも無い。

## コマンド

なし。

## クエリ

### 公演の集計を見る

その公演の主催者だけが、その公演の集計を見られる（仮説）。売れ行きと来場の数は、公演を企画した主催者の事業の情報で、ほかの公演の主催者に見えると競合に事業の状況が漏れる。来場者が見る理由も無い。運営スタッフがこの行いとして見るかは決めていない（「まだ決まっていないこと」参照）。

見せるのは、指定した一つの公演の、売れた枚数、分配された枚数、リセールで移った枚数、入場した人数の四つの数である。数え方は「業務用語」の各語のとおりで、見た時点までに持ち主の業務が記録した事実を数える。販売の開始の前から公演の後まで、いつでも見られる（仮説）。一件の公演の集計なので並び順は無い。

集計に持ち主の業務の事実が反映されるまでの遅れ（数分まで許す）は、業務の判断を変えないので品質要求に置いた（入場口の運用と非機能要件「整合性」）。

#### 拒む理由: その公演の主催者でない者が公演の集計を見る

公演の売れ行きと来場の数は、その公演を企画した主催者のものである。ほかの主催者や来場者に見せると、主催者の事業の情報が漏れる（仮説）。

# 導出されること

四つの数は、公演と見た時点から一つに決まる。売れた枚数はその公演で購入が成立したチケットの数、分配された枚数は承諾された分配のあるチケットの数、リセールで移った枚数はリセールの購入が成立したチケットの数、入場した人数は入場が一度でもあるチケットの数で、いずれも同じチケットを一枚と数える。

# 同時に起きたとき

なし。この業務は読むだけで、ぶつかる判断を持たない。

# まだ決まっていないこと

以下は、依頼元の指示で推奨を仮置きした答えと、答えを置いていない論点である。本文で「仮説」と書いた箇所は、ここの仮置きに当たる。

**業務をまたぐ問い: 一覧を分けて返すときの続きの位置（仮置き）。** 仮置きの答えは、並びの基準の値と、最後に返した項目を一つに決める識別で続きの位置を表し、一回に返す件数は API の契約に置く、である。この業務は一回に一公演の集計を返すので、一覧を分けることが起きない。根拠は、業務の分け方の一覧がこの問いを挙げながら答えを持たず、依頼元が推奨の仮置きを指示したことである。採らなかった案は、ページの番号で続きを表す案（間に事実が増えると項目が飛ぶかずれる）と、この資料だけで先に決めて他の業務を合わせる案（先着の決め方になる）である。決めるのは依頼元で、チケットの業務と同じ答えにする。

**業務をまたぐ問い: 一件ごとに見せる項目（仮置き）。** 仮置きの答えは、公演と四つの数である。四つの数は業務要件「後から説明できること」で決まるが、払い戻しの枚数や金額を加えないことは要件に無い。採らなかった案は、払い戻しになった枚数を加える案と、売上の金額を加える案（精算は対象外）である。決めるのは依頼元と主催者である。

**業務をまたぐ問い: 後から説明する相手と目的（一部仮置き）。** 運営スタッフが問い合わせに答えるため一枚のチケットの事実と順序を説明することは、業務要件「後から説明できること」で決まる。この業務が独自に説明のための記録を残さず、数の根拠を持ち主の業務の事実に置くことは仮置きである。根拠は、集計がほかの業務の事実を読むだけの業務だと業務の分け方の一覧が書くことである。採らなかった案は、主催者が見た時点の数を記録として残す案である。決めるのは依頼元で、主催者が「前に見た数」を説明として求めるかが分かれば決まる。

**業務をまたぐ問い: 対象の中の位置の表し方（持ち主に空けた）。** この業務は席や整理番号の位置を見せないので、位置を表さないことを仮置きした。席と整理番号の表し方そのものは主催者の管理機能が持ち主なので、この資料では答えを置かない。決めるのは主催者の管理機能である。

**業務をまたぐ問い: 業務の時刻を起きた時刻と受け付けた時刻のどちらにするか（答えを置かない）。** この業務は期間で区切らずに見た時点までの事実を数えるので、どちらでも四つの数は変わらない。入場、販売、リセールの業務が決める。主催者が「開演までに入場した人数」のように時刻で区切った数を求めるようになれば、この答えがこの資料の結論を変える。

**誰が公演の集計を見られるか（仮置き）。** その公演の主催者だけが見られ、ほかの主催者と来場者は拒む、と仮置きした。業務要件は主催者が知りたいと書くが、ほかの主催者を締め出すとは書いていない。採らなかった案は、運営スタッフもこの行いで見られる案と、主催者なら誰でも見られる案である。決めるのはステージパスの事業部と主催者である。

**売れた枚数を払い戻しで減らすか（仮置き）。** 払い戻しになっても売れた枚数から減らさない、と仮置きした。根拠は、主催者が知りたい四つに払い戻しが無く、減らすと「売れた」の意味が「今も有効」に変わることである。採らなかった案は、払い戻しになった枚数を差し引く案である。決めるのは主催者である。リセールの購入を売れた枚数に数えないことも同じく仮置きで、採らなかった案はリセールの購入も売れた枚数に足す案である。

**分配された枚数の数え方（仮置き）。** 承諾された分配のチケットだけを数え、同じチケットを一枚と数える、と仮置きした。承諾待ちが保有者を変えないことは要件で決まるが、「分配された」に承諾待ちを含めるかは要件に無い。再分配が認められるかは業務要件で未決である。採らなかった案は、分配を依頼したチケットを数える案と、分配の回数を数える案である。決めるのは主催者で、再分配の扱いはチケットの業務が決める。

**リセールで移った枚数を枚数で数えるか回数で数えるか（仮置き）。** 同じチケットが二度移っても一枚と数える、と仮置きした。根拠は、要件が「何枚が」と枚数で問うことである。採らなかった案は、リセールの購入の回数を数える案である。決めるのは主催者である。

**入場した人数で再入場を数えるか（仮置き）。** 一度でも入場したチケットの枚数とし、再入場は重ねない、と仮置きした。採らなかった案は、入場の回数を数える案である。決めるのは主催者である。

**通信断の間に同じチケットが二つの入口で入場したときの人数（仮置き）。** 一人と数える、と仮置きした。根拠は、どちらの入場を正しいとするかが業務要件で未決で、集計が二人と数えると入場の業務の判断を先取りすることである。採らなかった案は、入場の記録の数どおり二人と数える案である。決めるのは主催者と会場で、入場の業務がどちらの入場を正しいとするかを決めれば、この数え方も見直す。

**いつ見られるか、一回に何公演を見るか（仮置き）。** 販売の開始の前から公演の後までいつでも見られ、一回に一公演を見る、と仮置きした。根拠は、非機能要件が主催者向けの集計の遅れを許していて公演の途中にも見ることを前提にしていることと、主催者の公演の一覧は公演の持ち主の関心であることである。採らなかった案は、業務要件の文どおり公演の後だけ見られる案と、主催者の全公演を並べて見せる案である。決めるのは主催者とステージパスの事業部である。

ここまでの決まりが、具体の場面でどう働くかを示す。**ここに上で書いていない決まりを持ち込まない。** 場面の公演は、主催者 O-01 が企画した公演 P-0001（2026年12月5日 18:00開演、再入場を許す）とする。

## 公演の集計を見る

### [BDD-001] 主催者は自分の公演の四つの数を見られる

```gherkin
Given: 公演 P-0001 は主催者 O-01 が企画した公演である
  And: 公演 P-0001 では、チケット T-0001 から T-0004 の4枚の購入が成立している
  And: チケット T-0002 は同行者が分配を承諾し、保有者が同行者に変わっている
  And: チケット T-0003 はリセールの購入が成立し、保有者が買い手に変わっている
  And: チケット T-0001、T-0002、T-0003 は2026年12月5日に入場している
When: 主催者 O-01 が2026年12月5日 20:00に公演 P-0001 の集計を見る
Then: 売れた枚数4枚、分配された枚数1枚、リセールで移った枚数1枚、入場した人数3人が見える
```

### [BDD-002] 購入が成立していないチケットは売れた枚数に入らない

```gherkin
Given: 公演 P-0001 は主催者 O-01 が企画した公演である
  And: 公演 P-0001 では、チケット T-0001 と T-0002 の2枚の購入が成立している
  And: 来場者 V-0010 は抽選で2枚当選したが、支払期限までに代金を払っていない
  And: 来場者 V-0011 は先着で1席を確保し、支払いの手続きの途中である
  And: 来場者 V-0012 は席の確保が切れた後に支払いが成立したが、席が残っておらず購入は成立せず、代金を返された
When: 主催者 O-01 が2026年11月1日に公演 P-0001 の集計を見る
Then: 売れた枚数は2枚と見える
```

### [BDD-003] 払い戻しになったチケットも売れた枚数から減らない（仮説）

```gherkin
Given: 公演 P-0001 は主催者 O-01 が企画した公演である
  And: 公演 P-0001 では、チケット T-0001 から T-0004 の4枚の購入が成立している
  And: 公演 P-0001 は延期になり、チケット T-0004 は延期の払い戻しを受けて入場に使えなくなっている
When: 主催者 O-01 が2026年11月20日に公演 P-0001 の集計を見る
Then: 売れた枚数は4枚と見える
```

### [BDD-004] リセールの購入は売れた枚数に入らず、リセールで移った枚数に入る

```gherkin
Given: 公演 P-0001 は主催者 O-01 が企画した公演である
  And: 公演 P-0001 では、チケット T-0001 と T-0002 の2枚の購入が成立している
  And: チケット T-0001 は2026年12月1日にリセールの購入が成立し、保有者が買い手 V-0020 に変わっている
When: 主催者 O-01 が2026年12月2日に公演 P-0001 の集計を見る
Then: 売れた枚数は2枚、リセールで移った枚数は1枚と見える
```
